php2shell Scanner

CVE-2026-109618 & CVE-2026-109619 — CVSS 9.2, pre-auth RCE in PHP itself.
Patched in PHP 8.2.35 / 8.3.36 / 8.4.27 / 8.5.12 on 21 Oct 2026. Every older PHP serving web requests is affected — WordPress, Joomla, Drupal, Laravel, Magento and custom PHP alike. This checker is passive + benign only: it sends no exploit, no code, and nothing that can crash your server.

How to read the result
  • VULNERABLE — a PHP version below the fixed release was detected. Patch + restart PHP workers today.
  • PATCHED — detected version is at/above the fix. Distro backports can hide this — confirm the changelog names both CVEs.
  • INCONCLUSIVE — no version leaked (common, and good hygiene). It does not mean safe. Check on the server: php -v

Only scan sites you own or are authorised to test. Private/internal addresses are refused. Full source (CLI + this web app) is open — audit it before you trust it.

Official advisories: GHSA-w8hw-w9fx-j79w (CVE-2026-109618) and GHSA-6wmf-4rv5-p3rp (CVE-2026-109619) from the PHP security team. The only complete fix is updating PHP — there is no complete workaround.
